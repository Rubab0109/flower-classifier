# 🌸 Flower vs Not Flower Classifier

## 📌 Description
This project is a deep learning model that predicts whether an image contains a flower or not.

## 🚀 Features
- Detects flower vs not flower
- Provides confidence score
- Built using TensorFlow & MobileNetV2

## 🧠 Model
The trained model is stored on Google Drive due to size limitations.

## ▶️ How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run the script:
   python app.py

3. Enter image path when prompted

## ⚠️ Note
Make sure the model path is correct in app.py
